`@zenfg/inspector` 是用于检查 ZenFG Snapshot 数据的可嵌入式 DOM 工作台，与具体渲染器无关。它依赖 `@zenfg/snapshot`、Cytoscape 和 ELK，不依赖 WebGPU、wgpu、游戏引擎或宿主 UI。

<a id="installation"></a>

## 安装

<!-- generated:installation:start -->
```sh
npm install @zenfg/inspector@0.2.0
```
