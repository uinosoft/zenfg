# @zenfg/inspector 0.1.0

Date: 2026-09-15

First non-prerelease release of embeddable Snapshot Inspector, live capture and CPU/GPU timing views.

This release preserves the 0.1.0-beta.4 runtime behavior and public APIs.
Package metadata and documentation now identify 0.1.0; internal Snapshot
dependencies, where present, use the exact 0.1.0 release.

Snapshot remains version 1.2. Canonical 1.1 is explicitly migrated; canonical
1.0 remains rejected. No source migration is required from beta.4. For older
versions, see [the timing and Snapshot migration guide](../migration-timing-snapshot-1.2.md).

Published on the npm `latest` channel.
Public APIs may change before 1.0; pin exact versions when integrating.
