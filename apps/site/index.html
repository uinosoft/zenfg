SNAPSHOT + INSPECTOR

Understand the frame you actually built.

Follow declared dependencies, resource lifetimes, and diagnostics. Inspect optional CPU/GPU timings alongside the structure that explains them.

  1. Capture

    Capture an actual frame and locate the passes and resources that matter.

  2. Analyze with context

    Export Snapshot JSON with relevant code for human or AI-assisted analysis. Use the Inspector to give precise feedback about the flow.

  3. Change and verify

    Capture again after changes. Check the resulting graph and available timings rather than assuming an optimization worked.

External-engine internals stay opaque. GPU timing depends on device support and node coverage. Snapshots describe declared work; they contain neither replayable GPU commands nor resource contents.
